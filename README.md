# CodeTrust — Can You Trust AI-Generated Code?

CodeTrust is a web platform in development for evaluating and comparing Python solutions generated by different AI models.

The central question is: **When different AI models receive the same programming problem, which produces the most correct, secure, and efficient code?**

## Current status

Initial project documentation and repository setup. No application, dependencies, evaluation runner, or benchmark results are available yet.

## Planned approach

- Start with five standardized Python programming challenges.
- Collect model-generated solutions manually to avoid API costs.
- Evaluate functional correctness with Pytest.
- Inspect code quality with Ruff and potential security issues with Bandit.
- Define reproducible performance measurements and comparison criteria.
- Present real experiment results through a web dashboard.

Static analysis findings are signals for review, not proof that code is secure. The evaluation methodology will be documented before publishing comparisons.

## Execution safety

AI-generated solutions must be treated as untrusted code. They must not be executed directly on the primary machine. An isolated execution environment and resource limits must be agreed upon before implementing automated execution.
